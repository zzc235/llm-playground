油库工程概念
第一章 油库概论
 
1. 油库业务分为哪几方面
 
①生产基地油库：集积、中转油料；
②供销部门油库：平衡消费流通；
③企业附属油库：保障自身生产用油；
④国家储备油库：战略储备，应对非常规用油需求。
 
2. 油库分级分区的原因
 
油库储存易燃易爆油品，库容越大，火灾、爆炸事故损失越严重；从安全防火角度，按总容量划分等级，配套对应防火安全标准，保障油库整体安全。
 
3. 油库总容量分级标准
 
总容量TV指油罐公称容量+桶装油品设计容量，不含零位罐、高架罐、放空罐、自用油罐。
 
- 特级：1200000 \le TV \le 3600000 \ \mathrm{m^3}
- 一级：100000 \le TV < 1200000 \ \mathrm{m^3}
- 二级：30000 \le TV < 100000 \ \mathrm{m^3}
- 三级：10000 \le TV < 30000 \ \mathrm{m^3}
- 四级：1000 \le TV < 10000 \ \mathrm{m^3}
- 五级：TV < 1000 \ \mathrm{m^3}
 
4. 库容量确定方法；油罐选用注意事项
 
1. 确定方法：周转系数法、储备天数法。
2. 油罐选用要求：至少配备2座油罐；全库油罐规格尽量统一；优先选用大容量标准油罐。
 
5. 油库容量确定在设计中的作用
 
1. 生产调节：稳定向市场、工厂供应油品，集中来油时可全部入库，两次来油间隙保障供油；
2. 经济投资：容量合理可节约投资、缩短工期、发挥投资效益；
3. 容量失衡危害
- 库容过大：占地、建设成本高，储存损耗、运营成本上升；
- 库容过小：供油不足，阻碍生产经营，造成经济损失。
 
6. 油品按火灾危险程度分类
 
- 甲A：15℃蒸气压＞0.1MPa的烃类液体；
- 甲B：不属于甲A，闪点F_t＜28℃；
- 乙A：28℃≤闪点＜45℃；
- 乙B：45℃≤闪点＜60℃；
- 丙A：60℃≤闪点＜120℃；
- 丙B：闪点≥120℃。
 
7. 油库定义与作用
 
1. 定义：接收、储存、发放原油/石油产品的企业或单位。
2. 作用
- 纽带作用：协调原油开采、炼油加工、成品油运输与市场供应；
- 储备基地：国家石油战略储备、日常供应保障基地。
 
第二章 水路装卸油（油船、码头）
 
1. 油船装卸油流程设计基本原则
 
①满足油港多品种、多工况装卸作业；
②多油品同时装卸互不干扰；
③管线互为备用，单管线故障不中断作业；
④油泵互为备用，单泵故障可正常生产，多泵可并联同时工作；
⑤故障可快速切断油路，配套有效放空措施。
 
2. 油船类型、特点与用途
 
1. 油轮：自带动力可自航；配套输油、扫舱、加热、消防全套设备；远洋长途运输油品。
2. 油驳：无自航能力，依靠拖船牵引；依靠油库油泵、加热器作业；分内河、海上油驳，短途转运。
3. 储油船：无自航主机，吨位大于普通油船；海上油田离岸储存原油，保障海上采油连续生产。
 
3. 油轮管路系统组成
 
①输油管系统；②货油泵管路；③扫舱管；④蒸汽加热管；⑤专用压载水管；⑥洗舱管；⑦消防、惰性气体管；⑧酒水管；⑨透气气管。
 
4. 油港、码头选址考虑因素
 
①地质：岩石、硬黏土、沙质黏土地基，防止沉降位移；
②防浪：优选河湾、海湾避风处，无天然屏障则修建防波堤；
③水域面积：预留足够泊位、调度、拖船作业空间；
④水深：满足船舶吃水要求；
⑤泥沙：避开易淤积区域，减少清淤；
⑥间距：与客运、货运码头、桥梁等建筑保持安全距离。
 
5. 铁路槽车下部卸油优缺点
 
1. 优点：取消鹤管，解决夏季轻油卸油气阻；无需真空泵、扫底设备，结构简单、操作便捷。
2. 缺点：底部阀门频繁开关、行车震动易渗漏，运输安全性差。
 
第三章 油库管路、泵房、汽阻、热应力
 
1. 真空管路作用与组成
 
1. 作用：为离心泵、吸入管路、鹤管充油，抽吸油罐车底油；
2. 组成：真空管路、真空罐、真空泵、附属配件。
 
2. 油库管路敷设要求
 
①保证管路坡度；②阀门间距合理；③满足安全间距；④地上/管沟管路设支座、伸缩器；⑤地下管路分段设检查井；⑥全部管路做防腐、保温、防静电处理。
 
3. 管路试压合格标准
 
升压至试验压力150%，稳压查漏，渗漏处修补后重新升压；达到试验压力后稳压1h，压力无下降即为合格。
 
4. 汽阻定义、预防克服措施
 
1. 汽阻定义：鹤管卸油时，管路某点剩余压力≤油品输送温度饱和蒸气压，油品汽化形成气袋，阻断油品流动，破坏正常作业。
2. 预防措施
①压力卸油，提升罐内液面压力；
②降低油温，减小饱和蒸气压；
③减小鹤管内流速；
④优化鹤管结构，降低高度；
⑤扩大上游管路管径，降低沿程阻力；
⑥油泵向油罐方向前移、降低泵安装标高。
 
5. 减小管路温差热应力的方法
 
1. 地下管线：施工选温差小时段（冬季中午、夏季早晚），减小环境温差；
2. 地上管线：采用热补偿措施，敷设时不拉紧，预留弯曲伸缩余量。
 
6. 输油泵备用原则
 
1. 特殊专用油品：专用泵+配套备用泵；
2. 同油品连续输送：同时运行≤3台，设1台备用；运行＞3台，备用泵不少于2台；
3. 频繁间歇运转泵：不单独设备用，可与性质相近油泵互为备用或统一设1台公用备用；
4. 极少操作油泵：不设置备用泵。
 
第四章 油品加热、保温、伴热
 
1. 油品加热目的
 
降低管路输送水力摩阻，加快车船装卸；原油破乳脱水、沉淀杂质；促进油品调合；润滑油脂净化再生。
 
2. 油罐油品加热方法
 
蒸汽直接加热、蒸汽间接加热、热水垫层加热、热油循环加热、电加热。
 
3. 加热器形式及选型
 
1. 两种形式：局部加热器、全面加热器；
2. 选型
- 局部加热器：粘度低、不易凝固、单次发油量小的油品；
- 全面加热器：短时间内需要大量发油的油罐。
 
4. 大型全面加热器分段设置原因
 
①分段缩短管路，蒸汽摩阻减小，可低压供汽；
②降低蒸汽入口高度，减少底部“加热死角”；
③各组独立汽路、凝水管，单段故障可单独关闭，其余正常加热；
④可根据加热需求启停分段，灵活调节加热功率。
 
5. 全面加热器型式与选型
 
1. 型式：分段式、蛇管式；
2. 选型
- 蛇管式：润滑油、严格控含水、长期连续加热油罐；
- 分段式：不严格控含水、间歇加热、频繁调节加热面积的油罐。
 
6. 保温材料选用要求
 
①导热系数小，绝热性能优异；
②密度小，机械强度高；
③理化性质稳定；
④防潮、防水性能好；
⑤造价低、施工便捷。
 
7. 管路伴热适用场景与敷设要求
 
1. 伴热适用：流量小、间歇输送、不排空的粘油/易凝油管路，防止凝固、粘度陡增；
2. 敷设规范
- 水平输油管：伴热管布置在油管下部；
- 垂直管路：伴热流向与油品流向相反，自上而下，便于排出冷凝水。
 
8. 油罐、管线需要保温的8种工况
 
①介质温度需要恒定；
②介质温度＞120℃，回收余热；
③冷冻工艺，减少冷量损耗（保冷）；
④易凝介质，防止温度低于凝固点冻结；
⑤含水液化气，防止自冷结冰堵塞管路；
⑥减少日晒升温造成的蒸发损耗；
⑦设备壁温＞90℃，防止人员烫伤；
⑧室内高温设备，降低室温、改善操作环境。
