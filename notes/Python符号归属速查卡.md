# Python 符号归属速查卡

版本 v1 · 2026-09-16 · 一页版
用途：写完 / 报错时，从上往下扫一遍。**不背，用的时候看。**

---

## 一、报错时，先看这两个地方

报错信息通常三行，**只看两个位置**：

```
  File "E:\code\llm-playground\main.py", line 12    ← ① 去这一行
    prompt = f"请核对"\n{user_input}"                ← ② 看它指向的字符
SyntaxError: unexpected character after ...          ← ③ 类的名字，最后看
```

| 位置 | 看什么 |
|---|---|
| ① `line N` | **直接跳到那一行**，不要通读文件 |
| ② 那一行的箭头 / 引用 | 箭头指向的**那个符号**就是真凶 |
| ③ 错误类型 | `SyntaxError` = 符号写错；`TypeError` = 类型用错；`NameError` = 名字不存在 |

> **不要从报错信息里读「原因」**，报错只告诉你「在哪」，原因要自己看那一行。
> `Perhaps you forgot a comma?` 这类是**猜测**，不是诊断。

## 二、符号归属表（核心）

**读代码的顺序**：先找引号 → 再看 `f` → 再找括号 → 最后看「谁把它们接起来」。

| # | 符号 | 它管哪一段 | 踩过的坑 |
|---|---|---|---|
| 1 | `"` `'` | 一对引号 = **一个**字符串，中间不能断 | `f"…"\n{…}"` 引号断在半路 |
| 2 | `f` | 只管**紧跟它的那一个字面量** | `f"a" "b{x}"` → `{x}` 不生效 |
| 3 | `"""` | 只有**三个**引号能跨行；单个引号不能换行 | 多行 prompt 用了单引号 |
| 4 | `(` `)` `[` `]` `{` `}` | 必须成对；**从最里面往外数** | `'(' was never closed` |
| 5 | `\n` | 必须**在引号里面**才是换行 | `unexpected character after line continuation` |
| 6 | `,` | 只出现在 `()` `[]` `{}` **内部** | `Perhaps you forgot a comma?` |
| 7 | `:` | 只在 `if` / `for` / `def` / `with` 行**末尾** | — |
| 8 | 缩进 | 不是排版，**是语法**。同层必须对齐 | `prompt = …` 缩在 `with` 里面 |
| 9 | `=` vs `==` | `=` 放进去；`==` 问是否相等 | — |
| 10 | `.` | 点号两边**不能有空格** | — |
| 11 | `+` | 相邻字符串**没有 `+` 也会自动粘**，但 `{}` 不生效 | ⚠️ 静默失败，不报错 |

## 三、三条检查（防错 > 改错）

**① 引号计数**：一行里引号总数必须是**偶数**。奇数 = 少写一个，立刻补，别往下读。

**② 括号内视**：把光标放在 `(` 后面，VSCode 会高亮它的另一半。**用工具，别用眼睛数。**

**③ 一行一个动作**：长行拆短。

```python
# ❌ 一行塞三个动作，错了看不出错在哪
prompt = f"请核对以下笔记" + f"\n{user_input}"

# ✅ 拆开，每行一个动作
line1 = f"请核对以下笔记"
line2 = f"\n{user_input}"
prompt = line1 + line2
```

> 拆行不是「写得丑」，是给自己留出**一眼看出错在哪**的余地。

## 四、报错分类：这个错要不要练语法？

| 类型 | 例子 | 怎么处理 |
|---|---|---|
| **符号归属类** | `'(' was never closed`、`unexpected character after line continuation`、`inconsistent use of tabs` | **练这张卡**，用上面三条检查 |
| **静默失败类** | `f"a" "b{x}"` 不报错但 `{x}` 没生效 | ⚠️ **最危险**，写完必须问「我怎么知道它对了」 |
| **不知道某物是什么** | `No module named 'deepseek'`、`'dict' object is not callable` | **不是语法问题**，去查那个东西是什么，别往这张卡上记 |
| **顺序问题** | 变量赋值写在 API 调用之后 | 脚本从上往下一行行执行 |

## 五、每天 8 分钟日课

| 步骤 | 时长 | 做什么 |
|---|---|---|
| **看报错** | 2 min | 只找 `line N`，跳过去 |
| **拆行** | 3 min | 按表逐符号问「你管哪一段」；找不到就拆成 3 行，错会自己露出来 |
| **复述** | 3 min | 用大白话说一遍这行在干什么 —— **说不出来就是没懂** |

**唯一禁令**：不许「再读一遍教程」。读教程带来的进度感是假的。

---

## 六、一句话总纲

> **Python 的语法错误，八成不是「不知道这个符号」，是「没看清它管到哪一段」。**
> 写不出来的地方，拆行；报错的地方，先找引号、再找括号。
